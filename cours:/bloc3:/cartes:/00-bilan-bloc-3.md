titre: "Bilan Bloc 3 — comprendre le client, mesurer, piloter"
---
La démarche
  Piloter la performance des actions marketing et communication
  Connaître le client → cartographier le parcours → collecter les données → améliorer l'expérience → enquêter → mesurer → choisir les KPI → construire le tableau de bord → analyser les écarts et recommander
  Toujours : données fiables, RGPD, KPI actionnables, boucle d'amélioration
1. Connaître le client
  Marketing relationnel : partenaire avant acheteur, one-to-one
  6 sources de collecte, fichiers qualifiés
  Motivations repères : boussoles cachées, 6 catégories
  Matrice REPERE : 6 composantes reliées au parcours
  Client expert : communicant, co-constructeur, co-producteur
  Suspect → lead → prospect → acheteur → fidèle → ambassadeur
  6 étapes : vente la plus longue, transaction la plus courte
  Cycle de vie : atteindre, acquérir, convertir, retenir, fidéliser
  CLV = CA × durée − coûts ; ROMI au niveau micro ; RFM
  Segmentation : 9 types, arbre, 360°
  Ciblage : masse, différencié, multisegment ; pull vs push
    Cœur de cible, cible secondaire ; IAC
  Courbe d'adoption : 3 / 13 / 34 / 34 / 16 %, le gouffre
2. Cartographier le parcours client
  Point de contact, moment de vérité, ZMOT
  Point de défaillance plus grave que temps d'attente
  Pic d'émotion : les clients définissent leurs moments de vérité
  Scénario et carte d'expérience : points de contact, émotions, canaux
  Multicanal (silos) → cross canal → omnicanal (un CRM)
  FAQ = self care ; mail = 1er canal ; chatbot ≠ live chat
  ATWAD : AnyTime, AnyWhere, Any Devices
  Entonnoir : conscience, intérêt, considération, décision, action
    Retargeting par transition, A/B testing à une variable
  Growth hacking (Sean Ellis) : AARRR, risque RGPD
  Scénarios de Schwartz : tendances lourdes, signaux faibles, ruptures
3. Données, outils et RGPD
  Donnée brute → information ; 6 V
  Offline / online ; first, second, third party ; primaires à tertiaires
  Big Data (volume), Fast Data (temps réel), Smart Data (valeur)
  Stratégie défensive vs offensive ; data driven
  Big Quali, dataviz (Dataflow), data cleaning
  Data Lake (brut) ≠ Data Warehouse (structuré)
  Collecte multicanale : cartographier, Tag Manager, identifiants hashés
  5 critères de qualité : exactitude, complétude, cohérence, fraîcheur, granularité
  RGPD : 6 bases légales, intérêt légitime et test de proportionnalité
  Consentement libre, spécifique, éclairé, univoque, prouvé
  Registre, AIPD (2 des 9 critères), DPO
  Cookies exemptés, simplifiés, explicites
  Violation : CNIL sous 72 h ; 4 % du CA ou 20 M€
4. Expérience client et fidélisation
  Expérientiel : 4 phases, décor-intrigue-action, 5 modules
    Un détail négatif casse l'immersion
  Sensoriel : vue 80 %, tempo, dégustation, toucher, odeurs congruentes
  Thématisation (4 niveaux) et théâtralisation (énonciation, décor, acteurs)
  Phygital : click-and-collect, bornes, m-paiement
  Vendeur augmenté : connecté + IA, prescriptif ; beacons 70 m
  Conversationnel : temps réel ≠ relationnel long terme
  Alternatif : guérilla, street, ambush, stealth, ambient
  Fidéliser : 3 à 7 fois moins cher ; Peter Fisk +5 % → +25-55 %
    Mécontent en parle à 10, satisfait à 3
    5 clés : confiance, service, programme, écoute, offre
5. L'enquête de satisfaction
  La méthode de mesure la plus utilisée ; taux de retour = fiabilité
  Objectif SMART, jamais sans hypothèses
  Quali (pourquoi) vs quanti (combien) ; panel permanent
  Interne vs cabinet : décision selon le budget
  Structure en entonnoir : contact, blocs, identification à la fin
  Questions : « ne sait pas », « autre », filtre
  Échelles : Likert paire, numérique, Osgood
  Tester sur des personnes extérieures, pas par IA
  Échantillon : unité, taille absolue, aléatoire, quotas, itinéraires
  Modes : face-à-face, rue, téléphone, postal, Internet (CAWI)
  Outils : Sphinx, Ethnos, Google Forms, SurveyMonkey
  Risque ≠ problème ; AMDEC C = F × G × D ; 4 stratégies
  KPI d'enquête : réponse, abandon, complétion
6. Mesurer la satisfaction
  CSAT : % de satisfaits, ponctuel, sous 24-48 h
  NPS : 0-10, % promoteurs − % détracteurs, en points
    < 0 alarme, 0-20, 20-40, > 40 ; toujours par segment
  CES : effort, bas = bon ; fluidité > vitesse
  Rétention = (finaux − nouveaux) / initiaux ; churn ; fréquence
  Verbatims : codifier, quantifier, plan à 3 niveaux
  Analyse : cohortes, régression ; une seule échelle
  Alertes : NPS < +20, CSAT < 3,5, CES > 5
  Restitution : classique, web-reporting, dynamique
  Un message par destinataire, transparence sur le négatif
  Boucle de rétroaction : insight → pilote, deadline, KPI
  Une enquête max par client et par trimestre
  Audit client ≠ audit interne : 5 étapes de préparation
7. KPI et performance
  Performance = rendement face aux objectifs
  Data-driven : hypothèses → tests ; démarrer avec 3 KPI
  SMART version data ; KPI = prioritaire, actionnable
  Familles : visibilité, engagement, conversion, coût, fidélisation
  Reach, fréquence, part de voix ; rebond > 40 %
  ROAS = CA / dépense ≠ ROI = (gain − coût) / coût
  Action ≠ résultat ; vanity metrics
  Pyramide : 2-3 / 5-7 / 10-15
  Matrice KPI × objectifs, KPI Kill Process
  7 à 10 points de contact, ROPO, GA + CRM
  Attribution : last-click, first-click, linéaire, time-decay, en U, data-driven
8. Le tableau de bord
  Outil de pilotage : repérer au plus tôt les écarts
  Stratégique, opérationnel, budgétaire
  Simple, pertinent, synoptique, actualisé
  Ligne : calcul, cible, réalisé, écart, commentaire, action
  Pyramide de décision, navigation bidirectionnelle
  40 / 35 / 25 %, haut à gauche, lecture en Z
  Courbe, barres, secteurs ≤ 5, nuage ; rouge-orange-vert
  Stratégique : 5 KPI et « À retenir »
  Accès : consultation, analyse, administration
  Looker Studio, Power BI, Tableau, DashThis
  Rafraîchir selon les cycles de décision
  Alertes : SMS, e-mail, Slack
  Il alerte mais n'explique pas ; co-construire
9. Écarts et recommandations
  Quantifier (absolu, relatif, points), significativité, segmenter, hypothèses
  Benchmarks, cycles, journal d'événements
  Signal faible vs bruit ; corrélation ≠ causalité
  Investigation en 5 étapes, 5 pourquoi
  « Les moyennes tuent l'analyse » ; halo vs cannibalisation
  Impact / effort : quick wins ; ROI prévisionnel prudent
  Recommandation en 5 parties, adaptée au destinataire
  Plan d'action : RACI, jalons, critères d'arrêt
  Cercle vertueux en 6 étapes, 3 piliers
  PrepMyMeal : fiabiliser les données avant d'interpréter
