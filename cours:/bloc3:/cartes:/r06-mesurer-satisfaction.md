CSAT, NPS, CES : indicateurs d'attitude
  Ce que le client déclare
  CSAT : satisfaction ponctuelle
    % de satisfaits (4-5 sur 5)
    10/15/45/30 → 75 %
    Sous 24-48 h, formulation personnalisée
    Objectifs par canal, suivi mensuel
    TechnoSport : commande à 3,2/5, 40 % de paniers abandonnés
    L'échelle se choisit puis ne change plus
  NPS : propension à recommander
    Fred Reichheld, 2003, une seule question
    Échelle 0 à 10
      Promoteurs 9-10
      Passifs 7-8 : ne comptent pas
      Détracteurs 0-6
    % promoteurs − % détracteurs, de −100 à +100
    En points, pas en %
    TechnoSport : +10, pas +15
    Seuils
      < 0 : alarme
      0 à +20 : perfectible
      +20 à +40 : satisfaisant
      > +40 : avantage durable
    Par segment, en dynamique, pilotable
    7 jours après livraison (B2C), 30 jours (B2B)
    Toujours lire les verbatims
    +1 point ≈ +12 à 15 % de rétention
    Réseaux sociaux +45 vs comparateurs +12
  CES : effort fourni
    Prédit la fidélité mieux que la satisfaction
    % difficile − % facile, bas = bon
    Paradoxe de l'effort : fluidité > vitesse
      −40 % de rachat, +35 à 50 % de churn
    Cartographier le CES par étape
    Annoncer le sens de l'échelle
  Croiser les trois
    « Satisfaits mais frustrés » : −25 % de rachat
    Revenue per NPS Tier, Churn per CES Tier
Les indicateurs comportementaux
  Ce que le client fait
  Rétention = (finaux − nouveaux) / initiaux
  Churn = perdus / initiaux
  Fréquence d'achat = achats / clients uniques
  Exemple : 90 % de rétention, 10 % de churn
  Retirer les nouveaux, sinon rétention gonflée
  Banque 75 %, digital 30 % : même secteur seulement
