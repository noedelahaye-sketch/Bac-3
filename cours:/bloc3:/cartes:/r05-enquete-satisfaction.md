Pourquoi enquêter sur la satisfaction
  Le quanti valide ce que le quali comprend
  La méthode de mesure la plus utilisée
    Équilibre fiabilité et contraintes
  4 apports
    Rentabilité : réachat, buzz
    Fidélité : l'insatisfait communique plus
    Norme ISO : questionnaires réguliers
    Stimulant interne : écouter le personnel
  Le questionnaire ne permet pas de relancer
  Taux de retour : plus il est élevé, plus c'est fiable
    Optimiser la cible
    Donner envie : prévenir, communiquer
  Objectifs : axes d'amélioration, suivi, stratégie, former
  Émile Noël : 16,7 % → 15 %, la préférence locale
Le cadre de l'enquête
  Contexte : lancement, maturité, clients inactifs
  Pas d'objectifs sans hypothèses
  Objectif SMART
  Qualitatif : pourquoi, comment
    Motivations, freins, non-dit
    Limites : biais, situation artificielle
  Quantitatif : combien
    Limites : taille, durée, facteurs, analyse
  6 études qualitatives
    Préalable : débroussailler
    Image, positionnement
    Comportement : magasin test Auchan
    Motivation : le mobile caché
    Tests : paquet BN
  Investigation : entretiens, réunions, observation
  Quanti en 3 phases : recueillir, traiter, analyser
  Panel : enquête permanente
    Échantillon permanent et représentatif
    Vendu par abonnement
    Worldpanel, Homescan, Nielsen, IRI
  Cibles
    Externes : clients, puis partenaires
      Pas obligé d'exécuter leurs souhaits
    Internes : « trop d'études tuent l'étude »
  Interne vs cabinet
    Interne : rapide, peu cher, moins objectif
    Cabinet : objectif, pro, cher, lent, confidentialité
    Décision : le budget
Rédiger le questionnaire
  Méthodes de questionnement : résultats vérifiables
  5 W + H : diagnostic précis
  7 types (support questionnement)
    Ouvertes, fermées, orientées
    De contrôle : cohérence
    Alternatives, provocantes, stimulantes
  Biais d'endogroupe
  Règles de rédaction
    Attractives, compréhensibles
    Précises : combien d'heures par semaine ?
    Non biaisées : mémoire, prestige, milieu
  Longueur : 15-20 min plutôt que 45
  Structure en entonnoir
    Introduction : but, durée, remerciements
    Questions de contact simples
    Blocs thématiques, transitions
    Identification à la fin
  Types de questions
    Fermée : prévoir « ne sait pas »
    Ouverte : beaucoup de « sans opinion »
    Choix multiples : prévoir « autre »
    Classement
    Filtre : démasquer les fantaisistes
  Échelles
    Likert 1 à 4 : nombre pair pour trancher
    Numérique : 0 à 10
    Osgood : deux pôles opposés
  7 étapes : objectif, structure, élaboration, personnes, test, dépouillement, analyse
  Test : dizaines à centaines de personnes extérieures
    Pas de simulation par IA
  Expérience d'usage, de partage, de relation
Échantillonner
  Recensement seulement pour les niches
  3 décisions
    Unité de sondage : individu, foyer
    Taille
      Taille absolue, pas le rapport à la population
      Précision non proportionnelle
      La taille ne suffit pas
    Choix des individus
      Aléatoire : chance égale, la seule valable
      Quotas : mini-population
      Itinéraires : règles dans l'espace
      Arbitraire : intuitif, rare
  Toujours préciser méthode et taille
Diffuser l'enquête
  Taux de retour suffisant à coût maîtrisé
  Modes d'administration
    Face-à-face : sûr, cher, 20 min max
    Rue : gratuite, non représentative
    Téléphone : économique, bref, sans visuel
    Postal : non-réponse très élevée
    Internet : rapide, pas cher, biais technophile
  Enquêteurs professionnels, neutres, contrôlés
  CAWI + récompense
  Base e-mail : clients en ligne, interne, BtoB
  Bornes : smileys SFR
  Outils
    Sphinx : complet, coûteux
    Ethnos : 4 modules
    Google Forms : gratuit, simple
    SurveyMonkey : modèles, assistance
  Traitement : éliminer les incomplets, tris à plat
  Rapport : méthodologie, résultats, préconisations
L'approche par le risque
  Risque (incertain) ≠ problème (déjà là)
  Probabilité × impact
  Acceptabilité, impacts en cascade
  Typologie : stratégiques, opérationnels, financiers, RSE, RH
  Risques client
    Contractuel, juridique
    Réclamation : le plus nuisible à l'image
    Sur-réclamation
  Risque par étape du projet d'enquête
    Objectifs : stratégique
    Planification : délais
    Parties prenantes : mauvais ciblage
    Conception : inadéquation
  Données sensibles : minimiser, anonymiser, supprimer
  Management du risque : de réactif à proactif
    Oreo 4.0 et le Covid
  Processus itératif en 4 étapes
    Cadre : intelligence économique
    Identifier : signaux faibles → convergents → organisés → faits
      Data Mining : 5 traitements
    Évaluer : cotation AMDEC
    Traiter : plan, culture du risque
  4 stratégies
    Élimination : risque zéro
    Transfert : contrat, assurance
    Atténuation : formation
    Acceptation
  Normes : ISO 31000, 31010, 26000, 27005, COSO ERM
  PMRO : responsabilités, plan d'action, KPI
  Limite : cygne noir (Taleb)
  AMDEC : C = F × G × D
    Fréquence, gravité, détection
    4 niveaux, seuils indicatifs
  KPI du projet d'enquête
    Process : délais, taux d'erreur
    Input : budget
    Output : taux de retour, de réponse
    Leading : objectifs futurs
    Lagging : ROI, abandon, complétion
    Outcome : réachat, NPS
