# Q11 — Les supports de communication print et digitaux

**Un support**, c'est l'objet concret qui porte le message : plaquette, affiche, bannière web, vidéo, page web... La question demande du **print** (imprimé) et du **digital** — deux mondes techniques différents.

**Le cadre de cohérence.** Deux documents encadrent toute création ([R9](../resume/r09-contenus-supports.md), sections 3-4) :

- **La charte graphique** : les règles visuelles de la marque — logo (et ses règles d'usage), couleurs, typographies. Elle garantit qu'on reconnaît la marque sur tous les supports.
- **La ligne éditoriale** : les règles de fond et de ton — ce qu'on dit, comment on le dit, avec quel style.

**Les bases techniques** (version simple) : pour l'**imprimé**, une image doit être en haute qualité (300 dpi — la finesse d'impression) et en couleurs **CMJN** (le codage couleur des imprimeurs) ; formats papier normalisés (A4, A5, affiches...). Pour l'**écran**, une qualité standard suffit (72 ppp) et on travaille en **RVB** (le codage couleur des écrans) ; chaque plateforme a ses dimensions d'images. Le réflexe du cours : prévoir dès le départ toutes les déclinaisons de formats.

**Les bonnes pratiques visuelles** citées par les critères : équilibre texte/image, hiérarchie de l'information (l'essentiel d'abord — la **pyramide inversée**, qui vaut pour l'écrit comme pour le design), lisibilité, montage vidéo soigné. Côté rédaction, les techniques de titres, promesse et argumentation sont dans [R9](../resume/r09-contenus-supports.md), section 6.

**L'accessibilité** : rendre les supports utilisables par tous — contrastes suffisants, textes lisibles, **sous-titres** sur les vidéos, texte alternatif sur les images web.

**Le droit** (les deux notions que la question cite explicitement, en version simple) :

- **Le droit d'auteur** protège les **créations** (images, textes, musiques, typographies) : on n'utilise pas l'œuvre de quelqu'un sans autorisation ou licence. Les **banques d'images** vendent des licences d'utilisation ; les licences **Creative Commons** permettent des usages gratuits sous conditions.
- **Le droit à l'image** protège les **personnes** : pour montrer quelqu'un de reconnaissable, il faut son autorisation **écrite, précise et limitée** à un usage défini.

Pour approfondir : [R9 — Contenus et supports](../resume/r09-contenus-supports.md) (chartes, rédaction, réglementation complète, formats et outils de création).
